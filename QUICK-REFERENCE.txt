Why repository not showing after granting permission:

1. Propagation Delay (MOST COMMON)
   └─ GitHub takes 5-15 minutes to sync permissions
   └─ Solution: Wait and check again
   
2. Integration Not Authorized
   └─ Repository Settings → Integrations → Re-authorize
   └─ Solution: Remove and re-add integration
   
3. Organization Settings
   └─ Org may block third-party access
   └─ Solution: Check org integration policies
   
4. Wrong Access Level
   └─ Integration may need specific permissions
   └─ Solution: Grant Admin access (if needed)

All detailed in: PRIVATE-REPOS-ACCESS.md (Troubleshooting section)
